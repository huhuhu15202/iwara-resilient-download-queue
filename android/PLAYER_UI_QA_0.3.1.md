# 0.3.1 播放页与设置核验

日期：2026-10-07。交付：自用 APK `output/IwaraLocal-0.3.1.apk`，versionCode 6，使用原签名，可覆盖安装。

## 页面调整

- 白色观看页面；播放器与资料分区，不再重复排列大播放按钮。
- 常用操作统一为 44dp 高度的一排：上一条、下一条、音频、设置。
- 设置从底部打开，播放顺序、完成行为、速度、画面分组；保留选择，超出高度可滚动。
- 全屏旋转期间已打开的设置面板重新测量，不保留旧方向的高度。
- 真正的播放队列统一缩略图、两行标题、资料行；当前视频高亮。随机播放时按 Media3 实际随机顺序显示。

## 找到并修复的问题

退出后旧 Activity 可能仍绑定播放服务；系统通知的延迟 STOP 曾作用于随后打开的新视频。退出时现在释放旧 MediaSession 和播放器，新队列使用新会话。退出保存非末尾进度；重开保持暂停并从保存位置准备。

旧队列清理只移除自身快照，不移除替代队列的 active_id。无有效队列的错误页面不会请求停止其他正在使用的队列。

## 最终验证结果

Android 15 / API 35 模拟器，1080×2400、density 420。最终调试代码连续 3 轮、正式自用 APK 再 1 轮，每轮 `OK (6 tests)`，共 24 次测试执行。

- 原队列保存/恢复/清理、失效选择拒绝。
- 快照保持原可见顺序与选中起点。
- 清理旧队列不误删新队列。
- 四项队列的顺序/随机导航、列表循环、末尾停止与暂停状态保留。
- 真实临时 H.264/AAC 视频播放到结束；退出停止、保存有效进度、重新打开恢复且不自动播放。
- 集成测试内实际点击：随机、列表循环、1.5×、仅音频/视频、适应/填满，核对播放器状态和持久设置；关闭重开设置保留选择；全屏进入/退出。
