# Iwara 手机本地库 0.3.11

独立 Android APK，负责浏览、随机、搜索、作者/标签筛选，并使用 AndroidX Media3 ExoPlayer 在 App 内播放本地视频。播放列表由后台媒体服务持有，支持顺序/随机、单条/列表循环、上一条/下一条、音频模式和锁屏媒体控制。

## 使用

1. 安装 `output/IwaraLocal-0.3.11.apk`，Android 8.0 及以上。使用原签名覆盖安装，保留已同步资料、目录授权和隐藏记录，不需要卸载旧版本。

2. 底部“资料管理” → 电脑服务连接：选择“局域网”或“远程 Tailscale”。个人地址仅保存在本机被 Git 忽略的 `config.json`（`personalLanOrigin`、`personalTailscaleOrigin`），仓库不记录你的实际局域网或 Tailscale 地址。外网使用前需开启手机 Tailscale。通用构建若未配置个人地址会显示“未配置”。
3. 打开底部“资料管理”侧栏 → “同步电脑资料”。个人构建已经内置当前令牌，无需再粘贴链接。**个人 APK 的内置令牌可以被提取，请勿公开上传或转发**；它仅在私有临时构建目录生成，源码和 Git 不含实际令牌。连接设置仍以 Android Keystore 加密保存。同步的是经过筛选的 SQLite 资料副本，包含标题、作者、标签、上传日期、电脑下载完成时间、播放量和内容指纹；资料数据库不包含电脑路径、下载链接、Cookie、服务配置或密钥。
4. 资料管理 → 扫描文件夹 → 选择 / 更换视频文件夹，建议选择 `Movies/Iwara` 或 `Download/Iwara` 等子目录。系统授权会持久保存，包含子目录，重开应用后无需反复选择；资料管理显示选中的目录名。默认只扫描你选择的目录，不扫描整个手机；尚未选择时点“重新扫描”也会先要求选目录。系统视频媒体库扫描是明确选择后的可选项。Android 11+ 不允许通过目录选择器授权整个 Download 根目录，可选择其子目录或改用媒体库扫描。首次空列表也可直接点“选择视频目录”。
5. 授权后会自动扫描；后续新增视频可点“资料管理” → 重新扫描视频。视频会先显示；资料匹配后台进行。电脑关机或手机断网后仍可使用已同步资料及本地视频。

0.3.5：电脑手机资料同步纳入配置的外部媒体根目录；这些台账条目也会完成内容指纹并进入手机只读目录。手机点击同步后先等待电脑指纹任务完成或明确停滞，再拉取资料库并按完整 SHA-256 匹配，降低已扫描文件长期显示“未匹配”的情况。

如果电脑全库指纹还没有计算完，手机只关联当前已完成部分，其他项标记“未匹配”，仍能播放。稍后再次“同步”会补齐；它复用手机已计算的指纹，不覆盖隐藏状态。

“最近下载”按电脑台账的下载完成时间降序排列，不使用手机复制或文件修改时间；无电脑时间/未匹配的本地视频排在后面。筛选支持播放量高到低、低到高，未知播放量均排在后面。同步/扫描状态显示为上层提示，不改变列表高度，已有卡片直接更新，保留滚动位置。标题区根据系统字号分配两行空间，过长的标题两行省略，长按可查看资料。

## 清理手机重复视频

资料管理 → 清理重复文件。先按大小和采样筛选，再按完整 SHA-256 确认，不依赖文件名；未匹配电脑资料和已隐藏的视频同样参与检查。所有组默认不勾选，点击每组文件名可更改保留项。确认永久删除前再次完整校验，大小、修改时间或内容变化则跳过该组；同一物理文件的多个入口不会作为可删除副本。

只删除用户选中的手机副本，每组始终保留一份，电脑视频及台账不变。删除后手机映射保留历史，标记文件不可用。文件夹方式需要持久读写授权：资料管理 → 文件访问权限会明确显示“仅可读取，不能删除”或“持久读写授权已保存”。旧版只读授权不会自动升级；点“重新授权此文件夹”，在系统文件选择器中选同一个视频子文件夹并允许访问。授权后不会自动删除，需重新检查重复文件、选择副本并确认。选错文件夹不会更改原扫描范围。

删除前会核对目录读写授权和存储提供方的删除能力；权限不足直接显示重新授权入口，不再等完整哈希读完才提示失败。授权在操作中被撤销时也会保留未删除文件并显示结果；读取/查询失败不被当成“删除成功”。系统媒体库方式在 Android 11+ 仍使用系统删除确认；旧系统请选择文件夹授权后清理。无需申请整个手机的“所有文件访问权限”。这一点遵循 [Android SAF 文档](https://developer.android.com/training/data-storage/shared/documents-files) 和 [媒体删除确认机制](https://developer.android.com/training/data-storage/shared/media)。

## 匹配规则与范围

- 不依赖文件名、文件夹或视频 ID。先通过大小和版本 1 分段采样缩小候选范围，完整 SHA-256 才确认关联；采样相同不代表内容相同。
- 改名、复制到手机后内容未变化可匹配。转码、裁剪、重新封装后属于不同字节内容，当前版本不做感知匹配，标为“未匹配”。
- 同一完整 SHA-256 对应多条历史记录时显示“待确认”，不自动合并或猜作者。
- 只显示手机实际扫描到且获得读取授权的视频；电脑文件状态不用于判断手机是否存在。
- 长按卡片可隐藏/恢复、查看资料，不删除文件。实际重复副本删除只在资料管理的清理流程中进行；本地 APK 不提供下载功能。
- 底部“随机推荐”从当前筛选结果抽取最多 30 条，再点一次换一批。点击卡片把当前可见列表按显示顺序交给 App 内播放器，从所点视频开始；“随机播放”只打乱当前列表，不混入筛选外视频。返回视频库会停止播放；切到其他 App 或熄屏时保留当前播放队列。
- 原画和 480p 需要分别登记文件指纹，首版只同步电脑原文件的指纹；转码副本可扫描和播放，但不强行关联原画。

## 构建与验证

源码是原生 Android Java，使用系统 GridView 复用卡片；SQLite 资料与本地 URI 映射分开存放。封面本地截帧，两工作线程，内存 LRU 上限 16 MiB，无悬停预览。缩略图可由 Android 清除应用缓存；卸载前自行备份需保留的手机配置。

界面参考 [Mihon 库工具栏](https://github.com/mihonapp/mihon/blob/main/app/src/main/java/eu/kanade/presentation/library/components/LibraryToolbar.kt) 的搜索/筛选收纳和 [Fossify Gallery](https://github.com/FossifyOrg/Gallery) 的本地图库思路，图标自行绘制。统一大圆角、悬浮胶囊底栏、柔和浅蓝玻璃主题。

底栏使用 [AndroidLiquidGlassView 1.1.0](https://github.com/QmDeve/AndroidLiquidGlassView) 的 MIT 授权 AGSL 折射/色散着色器，原许可证保留在 `app/res/raw/liquidglass_effect.agsl` 并随 APK 打包。`GlassSurface.java` 是本项目的轻量渲染适配：只记录底栏大小的区域，不生成全屏位图、不使用持续刷新计时器，脱离窗口后释放 RenderNode。Android 13+ 使用真实背景模糊与折射，Android 8–12 或渲染器异常时使用清晰的半透明圆角底栏。它是 Android 的近似实现，不是 Apple 原生 Liquid Glass。卡片和搜索框仅使用玻璃主题颜色，不对每张卡片执行实时模糊。

```powershell
./tools/build.ps1
# 仅自用：从本机 config.json 注入私有令牌，不写入源码
./tools/build.ps1 -PersonalBuild
# 编译个人调试版本
./tools/build.ps1 -TestMode -PersonalBuild
```

便携 JDK/SDK、编译临时目录和签名密钥均存放在本机私有构建工具目录，不全局修改 Java 或 Android 环境。台账与服务数据库保存在配置的数据目录。保留本机 `signing` 目录以便后续 APK 覆盖更新；密钥不进入 Git。

未启用 `-PersonalBuild` 的通用构建不含令牌，仍可导入离线资料和扫描本地视频；当前连接选择界面针对个人固定地址构建，通用版本需自行配置凭据后才能在线同步。修改服务令牌或地址后需要相应更新个人构建。

服务新增接口（沿用现有局域网令牌，不能无授权访问）：

- `GET /api/mobile/han1me-download-codes`：只读扫描 `han1meDownloadRoot` 和 `han1meHistoryRoots` 中的媒体文件，合并重复项后返回唯一数字视频编号和计数；任一目录不可用时失败，不返回部分快照，也不返回电脑路径或媒体内容，供 Han1meViewer 同步 Room 去重记录。
- `GET /api/mobile/fingerprints`：电脑指纹进度。
- `POST /api/mobile/fingerprints`：启动或复用单工作扫描；已有外部扫描时不启动第二个。
- `GET /api/mobile/catalog.sqlite`：一致的手机资料数据库，响应结束/中断后清除临时导出文件。
- `GET /mobile-app.apk`：下载签名 APK。

电脑仍以现有台账为资料来源，手机扫描不会反写电脑下载状态或修改真实视频。

## App 内播放器

播放器使用 AndroidX Media3 ExoPlayer，通过本地 `content://` 地址读取视频。播放队列保存在 App 私有目录，完整队列不会塞进 Intent。打开视频自动播放；正常返回退出播放页会停止并释放会话。主动点击“浮窗”进入系统画中画时继续播放，关闭浮窗停止。播放器设置 → 后台播放可选择“自动进入画中画”；打开后，在播放中的二级页或全屏页切换到其他应用/返回桌面会自动进入系统 PiP，默认关闭；普通切到后台暂停视频，仅音频模式仍保留背景聆听。此功能使用 Android 原生画中画，不需要“显示在其他应用上层/悬浮窗”权限；若未触发，请在系统应用设置中允许本应用使用“画中画”。

音频模式会停用视频轨道；视频模式按内容 SHA-256、电脑台账 task ID 或本地 URI 选择进度键，音频模式不会写入观看进度。双击播放/暂停；左右横滑预览并定位进度，底部进度条也可拖动；控制栏不再显示 ±10 秒按钮。长按临时 2 倍速。容器和编码兼容性仍需用实机样本核验；播放器不会自动转码。

0.3.11：移除播放器控制栏中的 10 秒快退/快进按钮，保留拖动进度条与左右滑动定位。新增可选的后台自动画中画设置，支持在播放页或全屏播放时切换应用/返回桌面后继续在系统 PiP 中播放；默认关闭，不申请悬浮窗权限。设置弹层打开时不会意外自动进入 PiP。

0.3.1 将二级页面收敛为播放器、标题资料、单行上一条/下一条/音频/设置和真实播放队列。设置由底部面板分组展示，保存顺序/随机、循环模式、速度和画面适配；内容超出屏幕时可滚动。队列按实际随机顺序排列，当前项高亮，暂停时不显示虚假的“播放中”。退出后旧系统媒体会话立即释放，避免通知栏延迟停止指令干扰重新打开的视频。

0.3.2 将二级页“展开全部”改为以当前视频为中心的 32 项起始窗口，滚动时前后各追加 24 项，列表最多保留 56 张卡片；封面只为屏幕可见项排队，后台同时/排队任务合计最多 8 个，完成后直接更新对应图片，避免逐项遍历整页。播放器全屏时让舞台填满横屏区域，并在支持的设备上延伸到刘海短边区域，消除不对称安全边距；视频左侧上下滑调节亮度、右侧上下滑调节媒体音量，双击跳转和长按倍速保持不变。视频库与随机推荐之间支持在卡片网格上横向滑动切换；切换保留同一个玻璃底栏，只在内容更新后重录其局部背景。

0.3.3 增加视频区域左右滑动进度预览，松手提交一次跳转，取消手势不改变进度，暂停/播放状态保持不变；中央播放图标也支持拖动，不会吞掉手势。全屏按播放器实际视频尺寸选择横屏或竖屏，队列切换时自动跟随新视频，退出全屏恢复进入播放页时的方向。播放尺寸暂时未知时保持当前方向，避免每次切换都先竖后横。全屏封面与“适应画面/填满屏幕”设置保持一致。个人版 APK 是本地构建产物，不纳入 Git。
