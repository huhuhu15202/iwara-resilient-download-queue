# 0.3.3 手势、竖屏全屏及使用流程核验

日期：2026-10-07。个人版，versionCode 8。原 0.3.2 安装包保留；不改真实视频、台账或手机数据库，不上传 GitHub。

## 修复

1. 视频区域左右滑动显示目标时间和前进/后退量，松手只提交一次跳转。拖动取消或视频已切换时不提交；不会因拖动自动开始播放。
2. 手势一旦判断为横向/纵向就锁定方向，避免同一次拖动又改变进度又改变音量。中央播放图标上的拖动同样转交播放器；普通点击仍播放/暂停，长按松手不误触播放。
3. 全屏根据播放器实际 VideoSize（包括像素宽高比）决定方向：竖向或方形视频竖屏、横向视频横屏；队列切换后跟随新的尺寸。尺寸暂时未知时不反复转屏；退出全屏恢复原方向。
4. 全屏封面的适应/填满模式跟随播放器设置，不再播放前裁剪、播放后留边。
5. 播放、进度条和设置触控区域至少 44dp；手势提示按两行内容自适应高度，避免进度预览文字截断。

尺寸来源使用 Media3 [VideoSize 官方接口](https://developer.android.com/reference/androidx/media3/common/VideoSize)，不根据文件名猜测方向。
