# APK 0.2.1 删除授权修复

## 原因和改动

代码核验发现旧版目录选择流程接受系统返回的只读授权，却仍把目录显示为“已授权”；删除前没有核对持久写入授权，错误只短暂出现在状态提示里。尚未读取用户实体手机的权限或日志，不能保证这就是其手机的唯一原因。

- 新增 `StorageAccess`，把 SAF 目录授权与媒体读取权限区分开，核对持久读写授权和提供方的 `FLAG_SUPPORTS_DELETE`。
- 资料管理新增“文件访问权限”，显示未授权、只读或读写授权状态，并提供重新授权入口。
- 删除前预检，缺权限时不进行整文件复核或删除，打开提示，可选择同一个文件夹重新授权。
- 系统选择器会定位原文件夹；不同文件夹不能冒充原授权，也不更换扫描范围。
- 重新授权后不会自动恢复删除，必须重新检查副本、选择保留项并确认。
- 实际删除时再次检查权限；操作中失去权限或失败时显示结果和重新授权入口。查询失败不再当成“已删除”。
- 不申请整个手机的 `MANAGE_EXTERNAL_STORAGE`，不删除电脑视频，不修改电脑台账或已有观看状态。
- 版本 code 3 / name 0.2.1，沿用原签名，私有构建保持固定局域网/远程连接。

依据：[Android SAF 目录授权与持久权限](https://developer.android.com/training/data-storage/shared/documents-files)、[系统媒体删除确认](https://developer.android.com/training/data-storage/shared/media)。
