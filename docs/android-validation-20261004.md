# Android 本地库 0.1.0 验证记录

本轮构建 `android/output/IwaraLocal-0.1.0.apk`，签名 v2/v3 校验通过。测试使用独立 Android 35 模拟器及单独的 ADB 5038 服务，不安装测试程序到真实手机。电脑原视频未移动、改名或删除；测试副本只放在模拟器。

## 已通过

- Node / Java 内容采样哈希与完整 SHA-256 一致。
- 后端 113 项测试通过，指纹作业修改测试时序后连续四轮通过。
- 原生 SQLite 导入、未知文件、相同内容多记录冲突、隐藏状态保留、标签筛选与外部播放器调用通过。
- 真实局域网服务同步 2,276 条台账，约 1,981 ms；当时 749 条指纹已就绪。数据库只包含手机所需资料，不导出生产路径、令牌或服务配置。
- 230,591,833 字节的真实视频复制到模拟器，以不含 ID 的任意名称匹配：初次扫描 858 ms，再改名后扫描 162 ms。复制耗时 44,744 ms 包含模拟器网络和存储开销，不作为物理局域网测速。
- 实际点击系统 DocumentsUI，选择 `Movies/IwaraIsolatedTest`，确认持久读取授权。强制关闭并重开应用后授权仍在。
- 所选文件夹递归扫描 6 个测试视频（含子目录），目录外副本未进入列表。再次修改 220 MiB 副本名称后，SAF 内容指纹仍正确匹配。该轮扫描 2,834 ms。
- 外部模拟 MX 接收 SAF URI，并成功读取 4,096 字节，证明跨应用只读授权正确传递。
- 411 dp 手机及 800 dp 平板尺寸：底栏图标与文字横向中心一致，卡片等高，无横向溢出，随机推荐最多 30 项，重建 Activity 保留该批顺序。
- API 35 的 AGSL 着色器实际启用；玻璃只覆盖底栏范围，静止时不持续重绘。卡片和搜索框不执行实时模糊。
- 局域网 APK 地址无授权返回 401；有效令牌返回 200，与本地签名 APK 内容逐字节一致。

## 仍需实机确认

手机系统目录选择器的厂商差异、真实 MX Player 播放、触控和滚动体感。API 26–32 采用半透明回退，代码已隔离 API 33 类，但本轮没有旧系统模拟器的实测。

后台电脑全库指纹继续计算，当前 APK 无需等待其完成。未匹配视频仍可播放，之后再次同步可关联新完成的指纹。测试报告不表示全库扫描已经结束，也不表示 MX 自动连续下一条已实现。
