个人构建 `android/output/IwaraLocal-0.2.0.apk`，Android versionCode 2；保留原签名，APK v2/v3 验证通过。实际令牌仅由构建脚本从本地配置注入私有临时资源文件，源码检查未发现该令牌，APK 和配置被 Git 忽略。个人 APK 可被逆向提取令牌，不应公开发布。

## 本轮改动

- 状态提示放在 GridView 外的 FrameLayout 上层，点击可关闭，任务完成后自动消失，不为每条进度消息改变列表高度。可见封面完成时仅更新对应 ImageView，不通知全列表重建。
- 同步/扫描中按 URI 保留已有顺序及滚动锚点；任务完成后按当前排序整理一次，在顶部浏览时仍保持顶部。随机批次不因资料更新重新洗牌。
- 连接设置改为局域网/远程 Tailscale 两项，个人 APK 内置当前凭据；既有手机连接和加密配置保持兼容。
- 增加完整 SHA-256 重复副本检查，包含未匹配及隐藏项；默认不勾选任何组，可手动选择保留项。确认清理前强制重读全部内容，保护保留项、排除同一物理文件的重复入口；中断/文件变化则跳过，不碰电脑文件。手机映射记录不删除，只标记文件不可用。
- 播放量高低排序，未知值放在后面；最近下载按电脑台账 `completedAt` 导出的毫秒时间，不按手机文件修改时间。
- 手机数据库 v1→v2 增加可选 `download_time` 列，不清空本地映射和隐藏记录；旧十列导出仍可导入。电脑导出是精简资料副本，生产数据库和 taskId 不变。
- 两行标题及单行作者区按系统字号计算统一高度，解决第二行垂直截断和中英文行高不同；长标题仍采用两行省略，可长按查看。
